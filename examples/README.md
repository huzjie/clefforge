# Examples

每个脚本可直接 `python examples/<name>.py` 运行（零外部依赖）。

| 脚本 | 演示内容 |
|---|---|
| `demo_decide.py` | 单次决策（文本 / 多模态） |
| `demo_train.py` | RL 微调：准确率从近随机到 1.0 |
| `demo_bench.py` | 四组基准跑分 |
| `demo_calibration.py` | 置信度校准（ECE / Brier） |
| `demo_routing.py` | 快慢路由决策 |
| `demo_serve_client.py` | 起服务 + 客户端调用 |
