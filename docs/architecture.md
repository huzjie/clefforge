# 架构总览

## 数据流

```
query + options [+ image]
        │
        ▼
  ┌─────────────┐
  │  Router     │  按任务难度选 clef-flash / clef
  └──────┬──────┘
         ▼
  ┌─────────────┐     ┌──────────────┐
  │  Vision      │────▶│  Projector    │  图像 -> 视觉 token
  │  Encoder     │     └──────┬───────┘
  └─────────────┘            │
         ┌───────────────────┤
         ▼                   ▼
  ┌─────────────┐     ┌──────────────┐
  │  Backend    │────▶│  PointerHead  │  打分 logits
  └──────┬──────┘     └──────┬───────┘
         ▼                   ▼
  ┌─────────────┐     ┌──────────────┐
  │ Permutation │     │  Calibration  │  去顺序偏差 + 温度缩放
  └──────┬──────┘     └──────┬───────┘
         └─────────┬─────────┘
                   ▼
            ┌────────────┐
            │    Gate     │  accept / degrade / reject
            └────────────┘
```

## 分层

- **core**：零依赖张量 + 算子，所有后端的地基。
- **vision / fusion**：感知与多模态对齐。
- **model / decision**：Clef 模型与指针决策头。
- **backends**：可替换的推理后端。
- **train / data / bench / serving**：训练、数据、评测、服务。
